# Skill Check Simulator

A simple browser game for practicing skill checks. A needle spins around a ring, and you press Space, or click or tap the ring, when it is over the zone.

- **Standard:** a wide zone, with a check every one to three seconds.
- **Challenge:** a small zone and a fast needle, with checks back to back.

Fill the progress bar to 100% to finish a run. You can stop a run at any time, turn the sound off and adjust the volume. Best times are saved in your browser.

Built with plain HTML, CSS and JavaScript. No dependencies and no build step.
